# deckjson

Deck encode/decode helpers for json payloads in pipelines.

**Site:** https://theworker02.github.io/deckjson/

## Install / run

```bash
git clone https://github.com/theworker02/deckjson.git
cd deckjson
node src/cli.js
node --test
```
